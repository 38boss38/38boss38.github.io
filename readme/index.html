这是什么#

这是一个模拟 8 位机操作系统的个人网站。桌面上的图标就是内容目录，点开会在桌面上打开一个窗口。

底层还是 Hugo 生成的静态站点，所以每个窗口都对应一个真实的网址：可以直接分享链接、可以被搜索引擎收录、关掉 JavaScript 也能正常阅读。窗口管理器只是加在上面的一层壳。

桌面#

图标内容
文档博客、学习笔记和开发记录
游戏可以直接在浏览器里试玩的小游戏
作品视频、演示和其他个人作品
查找文件按关键词搜索全站
加密盘需要密码才能解密的私有目录
说明.txt就是这一页

点一次图标就会开窗，不需要双击。窗口可以拖标题栏移动、拖右下角缩放，也可以最小化到任务栏。同时开好几个窗口没问题，任务栏会列出全部。

左下角的开始按钮里有全部目录、外部主页、订阅源和「重新启动」。

任务栏右下角#

三个按钮，设置会记在浏览器本地：

  • Aa 切换正文字体。默认用系统的高易读字体，因为长篇笔记全用像素字体读起来太累；界面、标题和代码始终是像素字体。
  • CRT 三档：关、标准、强化。控制扫描线、荫罩栅格、暗角、回扫带和色相偏移的强度。觉得影响阅读就切到关。
  • ♪ 系统音效开关。浏览器要求页面被点过一次之后才允许发声，所以开机自检时通常是安静的。

系统会尊重操作系统的「减少动态效果」设置：开启后回扫带、闪烁和窗口动画都会停掉，开机自检也会一次性打完。

开机自检#

每个浏览器会话第一次进站会播放一次自检动画，按任意键或点一下就能跳过。里面的文档数、游戏数和加密盘条目数是真实统计出来的，不是写死的假数据。

想再看一次，用开始菜单里的「重新启动」，或者在网址后面加 ?boot=1。

加密盘#

加密盘里的内容在构建时就已经用 AES-GCM 加密过了，密钥由密码经 PBKDF2 派生。产物里只有一个 payload.enc.json 密文，没有明文页面，搜索引擎、订阅源和站内搜索都拿不到里面的东西。

需要说清楚的是：这是纯静态网站，没有服务端校验。密文是公开可下载的，短密码可以被离线暴力枚举——两位数字大概是毫秒级的事。所以加密盘适合放「不想被搜到、不想随便被看到」的东西，不适合放真正敏感的东西。

要换成更强的口令，构建前设置环境变量 VAULT_PASSWORD 即可。

游戏和视频#

游戏运行时和视频播放器都只在你点了按钮之后才加载。列表页、首页和文档页不会偷偷下载几十兆的 WebAssembly 或者连接第三方播放器。

游戏文件由外部主机分发，站内只保存封面、说明和嵌入地址。如果站内窗口加载失败，每个游戏页都有「新窗口试玩」作为备用入口。
